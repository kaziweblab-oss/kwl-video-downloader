      statusLine: slate-300 0.78rem via buildStatusLine(item) + getDisplayProgress(item)
        Queued/Pending → Queued (+ Size: X / Estimated ~ / Unknown if hasTotal)
        Converting → Converting to 3GP...
        Processing → Merging video and audio...
        Validating → Validating file...
        Completed → Completed
        Failed → Failed · error
        Cancelled → Cancelled
        Paused → Paused • 68% • 640 MB / 1.52 GB (via getDisplayProgress: hasTotal && pct!=null → 1-decimal precise, else indeterminate)
        Downloading → getDisplayProgress → mode determinate if hasTotal&&pct!=null&&!isPostProcessing else indeterminate
          determinate: `${pct}% • ${speed} • ${bytes} • ${eta}` where pct = max(item.percent, derived) rounded 10/10 clamped 0-100, speed formatBytes/s, bytes `${dl} / ${tot}` or `${dl} downloaded`, eta `ETA Xm Ys`
          indeterminate: `Downloading • 640 MB downloaded` or `Downloading...` (no total)
          Order always percent • speed • bytes • ETA
      Progress bar:
        showDeterminate = display.mode==='determinate' (hasTotal && pct!=null && phase not post-processing, plus Completed/Paused)
          <div mt1 h1.5 w-full overflow-hidden rounded-full bg slate-700>
            <div h-full transition-all duration-500 ease-out bg sky 400 (amber if Paused) style width `${Math.max(0,Math.min(100,progress))}%` />
          </div>
        showIndeterminate = display.mode==='indeterminate' (isDownloading&&!hasTotal || Merging/Converting/Validating)
          <div mt1 h1.5 w-full overflow-hidden rounded-full bg slate-700 relative>
            <div h-full w-1/3 bg sky 400 absolute inset-y-0 animation shimmer 1.2s ease-in-out infinite />
          </div>
          Keyframes shimmer 0% translateX -100% → 100% translateX 350% (index.css)

      DownloadingBroad (Downloading/Processing/Validating/Converting) → Pause (2 rects)
      Paused → Resume (play triangle)
      Failed → Retry (Icon retry)
      Completed + outputPath → Open file (doc) + Reveal in folder (folder)
      Always → Remove trash (delete)
  Note: Initially after Add, CartItem has percent 0, totalBytes from analyzed size (exact or approx) or null, downloaded null, so Queued shows Size, Downloading shows 0% with bar at 0% then moves via polling 1s

Polling: App.tsx activeJobSignature = cart.filter(jobId).map(id:jobId).join('|'), useEffect polls getDownloadJob(jobId) every 1000ms, applyJobToCartItem monotonic (Math.max) + phase floors 92/98/100, updates totalBytes via ?? (keeps analyzed until runtime reports), speed/eta hide when null.
